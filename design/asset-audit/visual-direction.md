## Style traits to carry into production

- **Bright, high-key colour:** saturated turquoise water, lush greens, warm sand and gold. No dark vignette.
- **Rounded, friendly shapes** with large-eyed characters and strong glossy highlights.
- **Thick dark-brown outlines** on icons and UI pieces; soft shading on the scenery.
- **A parchment, wood and rope UI kit** with green primary buttons. The app draws these in CSS from design tokens today; art is optional.
- **Currency and reward icons:** a gold coin with a star, a blue star for XP, a parchment map piece, an open treasure chest.
- **A "map as nodes on a path" language** (check, current ship bubble, padlocks), which is what the existing map markers already do in code.

## Mismatches between the reference and the game

The reference is a look, not a game spec. The built game differs, so the following are **not** to be produced unless the game changes:

| In the reference                                             | In the game                                                                                | Recommendation                                                                                                                                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gems (a third currency)                                      | Only COINS and XP exist                                                                    | No gem art. Use the gold coin and the blue star (XP)                                                                                                                               |
| Mini game ("Help Pip collect the coins")                     | No mini game                                                                               | Out of scope                                                                                                                                                                       |
| Seashell and starfish collectibles with counters             | Not in the item catalogue                                                                  | No art now; revisit if collections are added                                                                                                                                       |
| "Collect 3 Map Fragments" quest                              | Parrot Island's quest collects four compass feathers                                       | The copy is mock text; use the game's data                                                                                                                                         |
| Five nodes on a path (check, ship, two padlocks)             | Parrot Island has four authored locations: Pip, Feather Grove, Compass Shrine, Sunny Beach | A hotspot retune would be needed to follow the layout; none is applied. A natural fit, if approved: Pip at the lookout tower, Compass Shrine at the ruins, the Beach at the shore. |
| Pip wears a pirate hat                                       | Pip has no cosmetic today                                                                  | Pip sprite should include the hat                                                                                                                                                  |
| "Chore Quests" logo (gold letters on a hat badge, no ribbon) | Earlier concept boards show a different logo (with a red "Pirate Adventure" ribbon)        | One logo must be chosen; trademark clearance is pending                                                                                                                            |
